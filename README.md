# ReActRogueLike

A personal UE5 C++ learning project based on Tom Looman's ActionRoguelike sample.

## Overview

This is my **personal implementation** of a Co-op Action Roguelike game built with Unreal Engine 5.7 and C++.

I am following Tom Looman's *Professional Game Development in C++ and Unreal Engine* course while making numerous **personal modifications, experiments, and extensions** to deepen my understanding.

**Purpose**: Showcase my Unreal Engine 5 C++ development skills, system architecture understanding, and ability to implement and extend complex gameplay systems.

Not sure if I will build my own game based on these contents in the future

## Credits & Attribution

- Original Sample Project: [tomlooman/ActionRoguelike](https://github.com/tomlooman/ActionRoguelike) by **Tom Looman**

## Key Features Implemented / Modified

- Custom Action System (similar to simplified Gameplay Ability System)
- Attribute & Health System with proper damage flow
- Credit System(UE4 Legacy), PickupSubsystem
- AI Behavior Trees + EQS
- Projectile System
- ... (more personal experiments & improvements)

## Tech Stack

- Unreal Engine 5.7
- C++ (Primary)
- Blueprints (Minimal, for UI/Assets)
- Enhanced Input, Gameplay Tags, Data Assets, etc.
